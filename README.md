# Customer Shopping Behavior Analysis

A data analytics project focused on understanding customer shopping behavior using Python, MySQL, SQL, and Power BI. The project explores customer spending patterns, purchasing preferences, subscription behavior, and product performance.

## Project Overview

This project analyzes customer shopping data to identify useful patterns and generate insights that can support better business decisions.

The analysis includes:
- Data cleaning and exploration using Python.
- Storing and analyzing customer data using MySQL.
- Writing SQL queries to answer business-related questions.
- Creating an interactive dashboard in Power BI to visualize the results.

## Technologies Used

- **Python** – Data cleaning and analysis
- **Pandas and NumPy** – Data manipulation
- **Matplotlib and Seaborn** – Data visualization
- **MySQL** – Database management
- **SQL** – Querying and analyzing customer data
- **Power BI** – Dashboard creation
- **Jupyter Notebook** – Running the analysis

## Analysis Performed

The project explores the following business questions:

1. What is the total revenue generated by each gender?
2. How does discount usage affect customer spending?
3. Which products receive the highest average ratings?
4. How does shipping type relate to average purchase amount?
5. How do subscribed and non-subscribed customers differ in spending?
6. What are the discount rates across different product categories?
7. How can customers be segmented based on their previous purchases?
8. Which products are the top three in each category?
9. How do repeat purchases vary between subscribed and non-subscribed customers?
10. How does revenue vary across different age groups?

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/SayeeWagh/Customer-shopping-behavior-analysis-ml.git
cd Customer-shopping-behavior-analysis-ml
```

### 2. Set Up the Python Environment

Create and activate a virtual environment:

```bash
python -m venv .venv
```

On Windows:

```powershell
.venv\Scripts\activate
```

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy pymysql jupyter ipykernel
```

### 3. Set Up MySQL

Create the database in MySQL:

```sql
CREATE DATABASE customer_behavior;
```

Update the database connection settings in the notebook to match your local MySQL username, password, host, and database name.

**Note:** Run the notebook cells in order. The notebook performs the data preparation and loads the processed data into MySQL. If the table is written using `if_exists="replace"`, an existing table with the same name will be replaced.

### 4. Run the Jupyter Notebook

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open `Customer_Shopping_Behavior_Analysis.ipynb` and run the cells in sequence.

### 5. Execute the SQL Queries

Open `customer_behavior_sql_queries.sql` in MySQL Workbench or another MySQL client. Make sure the `customer_behavior` database and the required table have been created by running the notebook first.

### 6. Open the Power BI Dashboard

Open `customer_behavior_dashboard.pbix` using Power BI Desktop.

If the report requests database credentials or displays a data-source error, check its configured data source and credentials before refreshing the data.
